# MediCare+

Online doctor consulting platform providing quality healthcare consultations anytime, anywhere.

## Features Built So Far
- Modern landing page with interactive Header, Hero section, and quick Consultation booking
- Healthcare category explorer
- Testimonials and patient reviews section
- Frequently Asked Questions (FAQ) accordion
- Footer with social links and company information

## Project Structure
- `frontend/` - Next.js 16 (App Router), React 19, Tailwind CSS, Lucide & React Icons, shadcn/ui
- `backend/` - Node.js & Express server

## Getting Started

### 1. Frontend
```bash
cd frontend
npm install
npm run dev
```
Runs at [http://localhost:3000](http://localhost:3000)

### 2. Backend
```bash
cd backend
npm install
npm run dev
```
Runs at [http://localhost:5000](http://localhost:5000)
